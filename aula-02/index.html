Etapa 04

Rodar o prompt magico

~5min preparar

Agora a parte boa. Voce vai abrir o Claude Code no terminal, colar um prompt pronto, responder 4 perguntas, e ele vai trabalhar sozinho criando bot, subconta, fluxos, tudo.

📋 PROMPT EXECUTAVEL

Esse e o texto que voce vai colar no Claude. Voce nao precisa ler nada — so clica em "Copiar prompt completo" acima e depois cola no terminal (passo 4.7). O Claude se vira com o resto.

Mostrar o prompt (curiosidade — opcional)

Escolhe onde voce vai colar o prompt

4 caminhos, do mais simples ao mais bonito. Todos chegam no mesmo destino: bot rodando em ~70min. Recomendado: Cursor ou Antigravity (3 cliques cada).

CursorRecomendado
  1. Abre o Cursor (baixa em cursor.com se nao tem)
  2. Aperta Ctrl+L (Windows) ou Cmd+L (Mac) — abre o chat
  3. Clica em Copiar prompt completo acima, cola no chat (Ctrl+V), aperta Enter
cursor.com →
AntigravityRecomendado
  1. Abre o Antigravity (baixa em antigravity.google)
  2. Aperta Ctrl+I (Windows) ou Cmd+I (Mac) — abre inline AI
  3. Clica em Copiar prompt completo acima, cola, aperta Enter
antigravity.google →
VS Code4 cliques
  1. Abre o VS Code (baixa em code.visualstudio.com)
  2. Instala extensao: Ctrl+Shift+X, busca Claude Code, clica Install
  3. Ctrl+Shift+P, digita Claude: Open Chat, Enter
  4. Clica em Copiar prompt acima, cola, aperta Enter
code.visualstudio.com →
Terminal (CLI)5 cliques
  1. Abre o Terminal (Windows: Win+R, digita cmd)
  2. Digita claude e Enter
  3. Faz login se for primeira vez
  4. Clica em Copiar prompt acima
  5. Cola: Ctrl+Shift+V, aperta Enter
claude.ai/code →
