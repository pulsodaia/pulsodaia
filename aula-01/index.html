Instalacao

Tudo em 4 passos

Caminho recomendado: deixa o proprio Claude fazer a instalacao. Voce baixa, abre, cola um pedido.

Passo a passo

01
Baixe e descompacte o pacote
Clica no botao laranja acima, descompacta o ZIP. Voce vai ter uma pasta pacote-aluno com tudo dentro.
02
Instale o Claude Code (se ainda nao tem)
No terminal:
# Mac / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex
03
Abra o Claude Code dentro da pasta
cd pacote-aluno
claude
04
Cole esse pedido
leia INSTALAR-STACK-GHL.md e execute a instalacao
exatamente como descrito
Claude detecta seu sistema, cria as pastas, copia os 3 agentes, copia a skill, cria o template de credenciais, e te pede o token PIT do GHL pra preencher.
Validar

Como saber que ficou no ar

Abre um Claude Code novo em qualquer pasta e pergunta:

liste os agentes disponiveis e as skills com "ghl" no nome

Tem que aparecer @high, @revops, @convo e a skill triade-ghl-mastery. Se aparecer, esta tudo no ar.
