Material Complementar - Aula 01

Os 3 agentes e a 1 skill que eu uso pra operar GHL com Claude.

Este eh o stack que rodo em mais de 30 implantacoes TDI: clinica, alimentos, ecommerce, advocacia, sushi, odonto. Cada agente tem um escopo claro, e quando combinados eles cobrem 95% do que voce precisa fazer no GoHighLevel.

@revops @high @convo triade-ghl-mastery
01 / 04 - Agente

Rev - estrategista

R
@revops
Rev
Head RevOps - desenha o processo antes de qualquer ferramenta
O que ela faz
  • Desenha processos de Revenue Operations do zero
  • Define estrutura de pipeline, stages, criterios de qualificacao
  • Decide metricas que importam pro negocio (taxa de conversao por stage, tempo medio, motivos de perda)
  • Arquiteta fluxos antes da implementacao tecnica
  • Garante alinhamento entre marketing, vendas e CS
Quando usar e quando nao usar
Use a Rev quando
  • Vai montar um funil novo do zero
  • Cliente nao sabe explicar o proprio processo comercial
  • Tem mais de um time envolvido no pipeline
  • Precisa decidir quais campos custom criar antes de criar
Pule a Rev quando
  • So vai mexer em config ja aprovada
  • Bug tecnico de workflow (chama o @high)
  • Construir bot ou Voice AI (chama o @convo)
Exemplo real de prompt
@revops preciso de um funil comercial pra venda
consultiva B2B com ciclo de 30 dias. ticket medio
R$ 5k. quero saber as stages, gatilhos de avanco
e quais custom fields precisa ter pra eu medir
direito.
02 / 04 - Agente

High - executor do GHL

H
@high
High
GHL Specialist - implementa no GoHighLevel o que a Rev desenhou
O que ele faz
  • Cria, audita e reorganiza pipelines e stages
  • Configura workflows (Send SMS, Send Template, Wait, If/Else, Assign Owner)
  • Gerencia tags e campos customizados de Contact e Opportunity
  • Resolve bug tecnico (token expirado, typo de API, formato de payload, canal SMS vs WhatsApp)
  • Documenta todos os IDs criados pra voce poder reusar
Quando usar e quando nao usar
Use o High quando
  • Tem um desenho da Rev (ou ja sabe o que quer) e precisa montar no GHL
  • Workflow nao esta disparando e voce nao sabe por que
  • Precisa importar contatos via API com upsert
  • Auditar custom fields nao usados
Pule o High quando
  • Ainda nao decidiu o processo (chama a @revops)
  • Vai criar bot ou Voice AI (chama o @convo)
  • Quer escrever copy do template (chama o @copy)
Exemplo real de prompt
@high a Rev desenhou um pipeline B2B com 5 stages
(Lead, Contato, Qualificado, Proposta, Fechado).
implementa no GHL exatamente como esta no desenho.
cria os 3 custom fields que ela pediu, monta o
workflow de boas vindas e me devolve a lista de
IDs criados pra eu salvar.
03 / 04 - Agente

Convo - especialista em bots

C
@convo
Convo
Conversation AI Architect - bots, Flow Builder V3, Voice AI
O que ele faz
  • Cria bots de texto no GHL (qualificacao, agendamento, Q&A, suporte)
  • Desenha fluxos visuais no Flow Builder V3 (nodes, triggers, branching)
  • Monta agentes de Voice AI (inbound e outbound, com custom actions e webhooks)
  • Escreve prompts no framework RTG (Role-Task-Guidelines)
  • Treina Knowledge Base com URLs, Q&A, arquivos, tabelas
  • Configura acoes de IA dentro de workflows GHL
  • Domina a Conversation AI Public API (PIT / JWT)
Quando usar e quando nao usar
Use o Convo quando
  • Quer um bot atendendo no WhatsApp, IG, FB, SMS ou Web Chat
  • Vai construir agente de voz que atende ligacao
  • Precisa otimizar prompt que esta dando resposta ruim
  • Quer treinar o bot com base de conhecimento da empresa
Pule o Convo quando
  • Mexer em pipeline, field, tag (chama o @high)
  • Estrategia comercial antes do bot (chama a @revops)
  • Integracao com sistema externo (chama o @link)
Exemplo real de prompt
@convo cria um bot de qualificacao no GHL pra
captar lead via WhatsApp. perguntas: nome, faturamento
mensal, tipo de produto. se faturamento > R$ 50k,
move pra stage "Qualificado" do pipeline Comercial.
se < R$ 50k, marca tag "lead_pequeno" e encerra.
escreve no padrao RTG.
Comandos uteis
  • *create-bot - criar bot com prompt completo

  • *create-flow - desenhar fluxo no Flow Builder V3
  • *create-voice-agent - agente de Voice AI
  • *craft-prompt - prompt usando RTG framework
  • *train-bot - treinar knowledge base
  • *test-bot - plano de teste + Bot Trial
04 / 04 - Skill

triade-ghl-mastery - skill de bolso

SK
skill / triade-ghl-mastery
Mastery
Claude Code Skill - conhecimento empacotado que carrega sozinho
O que ela e

Skill nao eh agente. Skill eh um pacote de conhecimento que o Claude carrega automaticamente quando voce toca em assunto GHL. Voce nao chama, ela aparece sozinha. Funciona junto com os agentes acima e adiciona o conhecimento tatico que nao precisa de persona dedicada.

O que ela cobre
  • Gotchas de API: typo MONETORY, appoinmentPerSlot, PIT token expira, Cloudflare bloqueia python-urllib
  • Convencoes Triadeflow: nomenclatura de tags, padrao de discovery antes de criar, sempre user.first_name em template
  • Diferencas entre canais: Stevo intercepta SMS, WhatsApp nativo exige Twilio ou Meta pago
  • Rate limits: Meta WA template 1 edit por 24h, HUB rate limit por endpoint
  • Padroes de upsert: import de contatos via API com merge por telefone
Onde ela mora
~/.claude/skills/triade-ghl-mastery/SKILL.md
Como saber se esta ativa

Em qualquer conversa com o Claude, pergunta: liste as skills disponiveis com "ghl" no nome. Se aparecer triade-ghl-mastery, esta no ar.
