API Claude ajusta classificação automática para reduzir custos de produção.

A Anthropic implementou mudanças na sua API Claude focadas em otimizar a classificação de conteúdo para empresas. A alteração direciona essa função para processamento no lado do servidor, eliminando custos adicionais que antes poderiam ser cobrados.

Para quem utiliza ou planeja integrar modelos de linguagem avançados, como o Claude, em suas operações, essa modificação representa um alívio potencial nos gastos operacionais. A eliminação da cobrança específica pela etapa de classificação automática pode ser significativa, especialmente para cargas de trabalho de alta intensidade.

A atualização, presente na versão v2.1.278 do Claude Code, já está ativa em plataformas como Bedrock, Vertex e Foundry. A documentação detalha a nova abordagem de precificação e como desativar a configuração no servidor, se necessário.
