Novas habilidades no Claude Code 2.1.332 para desenvolvedores de IA.

A Anthropic liberou a versão 2.1.332 do Claude Code, trazendo novidades importantes para quem trabalha com desenvolvimento de IA. A atualização introduz funcionalidades derivadas de servidores MCP, ainda em fase beta.

Um destaque é o novo hook de evento `PreSkillShellCommand`. Ele permite que desenvolvedores recusem comandos de shell inline de skills ou comandos no exato momento em que são carregados. Isso significa um controle mais refinado sobre a execução de código e maior segurança nos fluxos de trabalho.

A atualização também melhora a experiência de mensagens entre sessões e adiciona um rodapé persistente para indicar quando o modelo da sessão atual difere do modelo original de uma mensagem. Monitoramento e análise também foram contemplados com um evento OpenTelem.
