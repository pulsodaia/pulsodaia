Hugging Face lança Olmo-core 3 para simplificar treinamento de modelos MoE.

A Hugging Face anunciou o Olmo-core 3, uma nova infraestrutura de treinamento. O objetivo é facilitar a criação e o escalonamento de modelos do tipo Mixture-of-Experts (MoEs).

MoEs utilizam múltiplos especialistas para processar dados de forma mais eficiente. O Olmo-core 3 visa reduzir a complexidade técnica e os desafios de infraestrutura associados a essas arquiteturas.

A iniciativa busca democratizar o acesso a ferramentas avançadas para pesquisa e desenvolvimento em IA, promovendo um ambiente mais aberto e colaborativo.
