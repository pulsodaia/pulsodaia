Claude Code ganha automação e personalização para desenvolvedores.

A Anthropic atualizou o Claude Code, focando em otimizar o fluxo de trabalho de programadores. A versão v2.1.234 traz novidades que permitem maior controle sobre a organização de dados e agilidade na manipulação de conteúdo.

Entre as adições, está a gestão de diretórios por sessão, possibilitando a definição de um nome curto para transcrições de projeto. Isso facilita a organização das interações com a IA. A atualização também inclui um atalho para limpar seleções de texto, acelerando a edição.

Para quem usa GitLab, um distintivo indica o status de requisições de merge diretamente no rodapé e na linha de status. Uma funcionalidade importante é a continuidade automática de sessões após atingir limites de uso da conta `claude.ai`, com opção de desativação.
