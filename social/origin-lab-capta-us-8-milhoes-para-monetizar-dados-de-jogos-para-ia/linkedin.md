Startups de jogos e IA: uma nova fonte de receita surgiu.

A Origin Lab captou US$ 8 milhões para criar um marketplace de dados de jogos. A plataforma conecta estúdios de videogames a laboratórios de IA focados em modelos de mundo.

Empresas de jogos podem licenciar dados de gameplay, interações de jogadores e comportamentos de personagens. Isso permite a monetização de ativos de dados antes subutilizados.

Laboratórios de IA, por sua vez, adquirem dados de alta qualidade para treinar modelos que replicam a complexidade do mundo real. Uma oportunidade para a indústria brasileira de games.
