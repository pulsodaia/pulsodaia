---

Microsoft desenvolveu um método para treinar IA usando bancos de dados como guia. A abordagem ThinkingBox transforma a qualidade dos dados em recompensas, simplificando o ajuste fino pós-treinamento.

Essa técnica elimina a necessidade de feedback humano constante, permitindo que a IA aprenda a gerar respostas consistentes com informações pré-existentes. Ideal para setores com muitos dados estruturados.
