Claude Code agora detalha seu uso.

A Anthropic atualizou o Claude Code, versão v2.1.149, com melhorias no monitoramento de recursos. Desenvolvedores podem agora ver um detalhamento por categoria do consumo, incluindo skills, subagentes e plugins.

A navegação no comando `/diff` também foi aprimorada, permitindo o uso do teclado para scroll. Isso facilita a análise de diferenças em código.

Novidades incluem também a renderização de saídas em Markdown com caixas de seleção para tarefas, distinguindo pendentes de concluídas. Para clientes corporativos, há uma nova configuração gerenciada para carregar conectores de nuvem.
