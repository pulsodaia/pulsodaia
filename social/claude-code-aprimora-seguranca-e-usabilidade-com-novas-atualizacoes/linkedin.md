Claude Code adiciona camadas de segurança e controle para desenvolvedores.

A Anthropic lançou atualizações para o Claude Code, focando em tornar o trabalho com repositórios mais seguro. Uma nova confirmação é exigida antes de quaisquer alterações serem aplicadas, prevenindo modificações indesejadas.

Além disso, o gerenciamento de tokens foi aprimorado. Agora, é possível adicionar tokens de servidor via entrada padrão, evitando a exposição direta na linha de comando. Essa mudança visa proteger credenciais de acesso.

A ferramenta também oferece mais clareza em caso de falha na recuperação de sessões. Uma mensagem informativa é exibida, explicando a limitação. O comando `/status` foi expandido para fornecer um panorama mais completo do ambiente de desenvolvimento.
