Claude Code agora aceita AGENTS.md para instruções de projeto.

A Anthropic atualizou o Claude Code para a versão v2.1.277, introduzindo o suporte ao arquivo AGENTS.md. Essa mudança permite que o sistema utilize um novo arquivo para instruções de projeto quando o CLAUDE.md não estiver presente. A configuração pode ser ajustada na seção "Project instructions" do arquivo `/config`.

A atualização também traz melhorias na gestão de rede para gateways de aplicativos Claude. A nova variável de ambiente `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1` otimiza o envio de requisições de saída, enviando o nome do host para o proxy em vez de tentar a resolução local.

Além disso, foi adicionada a opção de incluir um mapa `headers:` nas configurações de upstream dos gateways de aplicativos Claude. Isso facilita o envio de cabeçalhos estáticos para proxies que operam na frente de provedores de serviço.

Essas novidades visam oferecer mais flexibilidade e controle para desenvolvedores que utilizam o Claude Code em seus fluxos de trabalho e infraestrutura.
