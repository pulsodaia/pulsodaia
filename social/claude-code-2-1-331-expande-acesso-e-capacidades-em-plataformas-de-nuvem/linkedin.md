Claude Code 2.1.331 agora fala a lingua das grandes nuvens.

A Anthropic atualizou seu Claude Code, focando em facilitar a vida de quem desenvolve com IA. A novidade principal é o "Code Mode", agora disponível em plataformas como Amazon Bedrock, Google Cloud Agent Platform e Microsoft Foundry.

Isso significa que a interação com modelos de linguagem para gerar e analisar código ficou mais direta, independentemente da sua infraestrutura de nuvem preferida. A integração aprimorada simplifica o fluxo de trabalho para desenvolvedores.

A atualização também traz melhorias na gestão de acesso, com o Claude Apps Gateway lendo grupos de usuários via JSONPath. Para diagnósticos rápidos, a ferramenta `claude doctor` ganhou uma seção para verificar a conectividade da API.
