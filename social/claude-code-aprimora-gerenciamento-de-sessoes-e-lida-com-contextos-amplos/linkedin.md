Claude Code agora gerencia sessões ociosas e contextos amplos com mais eficiência.

A Anthropic atualizou o Claude Code, focando em estabilidade para desenvolvedores. A versão v2.1.311 introduz controles para manter sessões ativas mesmo quando o host reporta processos em execução, evitando interrupções.

Essa melhoria é crucial para fluxos de trabalho complexos, garantindo que o assistente de codificação permaneça responsivo e confiável.

Além disso, foram corrigidos bugs de longa data relacionados à inicialização e edição de arquivos com listas extensas. A interrupção de tarefas também ficou mais rápida.

O sistema agora compacta conversas que excedem 200.000 tokens, permitindo o processamento contínuo em vez de encerrar a sessão.
