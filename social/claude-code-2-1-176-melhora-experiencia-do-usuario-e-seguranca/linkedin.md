Claude Code 2.1.176 agora gera títulos de sessão no idioma da sua conversa.

A Anthropic atualizou o Claude Code com a versão 2.1.176, focando em aprimorar a experiência do usuário e a segurança. Uma das novidades é a geração automática de títulos de sessão, que se adaptam ao idioma predominante na conversa. Essa funcionalidade oferece maior conveniência e organização para os usuários.

A atualização também introduz a configuração `footerLinksRegexes`, permitindo a inclusão de links em formato de badge no rodapé da interface. Essa opção aumenta a flexibilidade na personalização e acesso a recursos externos.

Em termos de segurança, o cache de credenciais da AWS Bedrock foi otimizado. As credenciais agora são armazenadas até a data de expiração, garantindo um gerenciamento mais seguro e eficiente. A validação de parâmetros também foi reforçada para prevenir redirecionamentos indevidos.
