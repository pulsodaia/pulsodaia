Claude Code v2.1.274 eleva a estabilidade de sua operação.

A Anthropic lançou uma atualização significativa para o Claude Code, focada em aprimorar o gerenciamento de memória e a configuração de conexões. A nova versão introduz alertas visuais para uso crítico de memória, ajudando a prevenir interrupções inesperadas.

Um dos destaques é a variável de ambiente `CLAUDE_CODE_MCP_STARTUP_WAIT_MS`. Ela permite ajustar o tempo de espera para conexões com servidores MCP em interações não interativas, com a opção de desativar completamente essa espera.

A atualização também expande o rastreamento de telemetria, adicionando o atributo `effort` a eventos de requisição LLM e introduzindo um novo evento para maior visibilidade sobre fontes de configuração.
