Ferramentas de IA para desenvolvedores estão ganhando novas camadas de controle.

A Anthropic liberou atualizações para o Claude Code, focando em como múltiplos agentes de IA interagem. A nova ferramenta `Workflow` permite orquestrar esses agentes de forma determinística, prometendo maior controle em fluxos de trabalho complexos.

As sessões em segundo plano foram aprimoradas, mantendo-se ativas e reiniciando automaticamente para aplicar atualizações. A gestão de memória também foi otimizada para priorizar sessões fixadas.

A funcionalidade de revisão de código, agora chamada `/code-review`, foi refinada. Ela foca na detecção de bugs com um nível de esforço configurável e permite postar descobertas diretamente como comentários em Pull Requests do GitHub.
