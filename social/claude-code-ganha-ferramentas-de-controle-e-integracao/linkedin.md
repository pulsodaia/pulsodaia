Claude Code agora oferece mais controle para desenvolvedores.

A Anthropic atualizou o Claude Code (v2.1.285) com novas funcionalidades focadas em aprimorar a experiência do desenvolvedor. O objetivo é simplificar a gestão de plugins e a interação com o ambiente de desenvolvimento.

Uma das novidades é a variável de ambiente `CLAUDE_CODE_DISABLE_WEB_FETCH`, que permite desativar a busca na web, dando ao usuário maior controle sobre as fontes de informação. Além disso, foi adicionado o comando `claude --desktop` para abrir o aplicativo diretamente no diretório atual ou em uma sessão anterior.

A gestão de plugins também recebeu otimizações. O comando `claude plugin configure` agora exibe as opções disponíveis e as que ainda não foram definidas. A instalação de plugins foi agilizada com o parâmetro ` . = ` dentro de `claude plugin install --config`, permitindo definir configurações específicas de servidores MCP no momento da instalação.
