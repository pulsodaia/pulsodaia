Anthropic ajusta Claude Code para dar mais controle a desenvolvedores.

A plataforma Claude Code da Anthropic recebeu atualizações significativas com a versão v2.1.267. O foco principal é oferecer aos desenvolvedores maior precisão no uso de modelos de linguagem.

Uma das novidades é o controle `maxEffortLevel`. Ele permite definir o esforço computacional máximo para provedores como Bedrock, Vertex e Foundry. Isso dá mais flexibilidade para gerenciar recursos.

Outra melhoria é o comando `--system-prompt-snapshot off`. Ele possibilita testar prompts de sistema de forma isolada em cada solicitação, facilitando a iteração e o refinamento.

A atualização também resolve bugs. Problemas com tarefas agendadas e renderização de saídas em branco foram corrigidos, além da restauração de funcionalidades de atalho.
