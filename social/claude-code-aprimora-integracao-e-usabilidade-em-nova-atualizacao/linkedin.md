Anthropic atualiza Claude Code com foco em usabilidade e segurança.

A versão v2.1.275 do Claude Code traz melhorias para usuários de terminais. A integração com contas logadas no Claude apps permite confirmação de credenciais e exibição de status, aumentando o controle do usuário.

Uma nova tecla de atalho (Ctrl+Enter ou Ctrl+X Ctrl+S) agiliza o envio de mensagens, enquanto o feedback visual em cinza para mensagens em espera e pendentes clarifica o fluxo de comunicação.

A atualização também inclui um aviso para falhas na configuração de telemetria e sincroniza skills e plugins habilitados no claude.ai para conexões via terminal, com opção de desativação.
