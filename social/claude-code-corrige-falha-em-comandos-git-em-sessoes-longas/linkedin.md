Claude Code ajusta falha em comandos Git que exigia permissão indevida.

A Anthropic lançou a versão v2.1.270 do Claude Code, corrigindo um comportamento inesperado em comandos Git. A falha solicitava permissão mesmo em operações somente leitura, especialmente em sessões de desenvolvimento prolongadas.

Esse problema causava interrupções desnecessárias no fluxo de trabalho dos desenvolvedores. Em um ambiente que valoriza a agilidade, tais atritos podem impactar a produtividade.

A atualização resolve essa regressão, garantindo que comandos Git em modo somente leitura funcionem como esperado, sem interrupções.
