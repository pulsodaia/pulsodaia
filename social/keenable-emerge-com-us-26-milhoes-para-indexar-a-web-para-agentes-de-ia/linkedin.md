Startup arrecada US$ 26 milhões para organizar a web para agentes de IA.

A Keenable, operando discretamente, anunciou um aporte significativo em rodada seed. O foco é construir um índice web voltado para as necessidades de agentes de inteligência artificial.

Em vez de indexar para usuários humanos, a empresa está desenvolvendo uma infraestrutura de busca otimizada para que sistemas de IA possam interagir e extrair informações de maneira eficiente.

Essa iniciativa aborda o desafio crescente de organizar a informação online para consumo por software, impulsionado pelo avanço da automação e das capacidades de agentes de IA.
