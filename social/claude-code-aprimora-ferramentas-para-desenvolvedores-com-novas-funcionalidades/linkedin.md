Claude Code atualiza ferramentas para desenvolvedores.

A Anthropic liberou a versão v2.1.292 do Claude Code, trazendo aprimoramentos para otimizar o fluxo de trabalho de programadores. Uma das novidades é a instalação de plugins via linha de comando, que agora inclui um marketplace.

O controle sobre o nível de esforço de agentes foi expandido, permitindo maior flexibilidade na execução de tarefas. Para lidar com picos de demanda, foi adicionada uma variável de ambiente para configurar o atraso em retentativas de requisições sobrecarregadas.

Essas atualizações visam simplificar a integração de novas funcionalidades e o gerenciamento de recursos, tornando a plataforma mais eficiente para quem desenvolve.
