Claude Code ganha modos de saída mais diretos.

A Anthropic liberou a versão v2.1.237 do Claude Code, focando em otimizar o uso para desenvolvedores. A atualização corrige problemas de cache em fluxos de trabalho que usam gateways LLM ou URLs base personalizadas. Isso garante maior estabilidade em ambientes de desenvolvimento.

A novidade mais perceptível é o estilo de saída "Conciso". Ele apresenta os resultados diretamente, sem introduções longas. O objetivo é manter a qualidade técnica, mas com mais eficiência na comunicação. Essa opção pode ser escolhida nas configurações.

Essas mudanças são importantes para o mercado brasileiro de tecnologia, oferecendo ferramentas mais eficientes e claras para o desenvolvimento.
