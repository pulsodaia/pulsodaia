Claude Code ganha modo rápido na Vertex AI, otimizando processamento de LLMs.

A Anthropic atualizou o Claude Code com um "modo rápido" para a Vertex AI, serviço de machine learning do Google Cloud. A novidade visa agilizar a execução de modelos de linguagem em infraestruturas de nuvem globais, com disponibilidade nas regiões EUA, Europa e global.

Quando a Vertex AI não consegue atender a uma solicitação no modo rápido, o sistema reverte automaticamente para a velocidade padrão. Essa funcionalidade oferece maior flexibilidade e eficiência para desenvolvedores que utilizam a plataforma.

A otimização de performance em nuvem é essencial para o mercado brasileiro de IA. Processamento mais rápido de modelos de linguagem pode significar custos menores e tempos de resposta reduzidos para aplicações de IA, de chatbots a sistemas de análise de dados.
