Anthropic lança modelo "Mythos-class" para uso geral.

A Anthropic apresentou o Claude Fable 5, um novo modelo de linguagem classificado como "Mythos-class". A empresa indica que esta versão supera todas as anteriores disponibilizadas publicamente.

O Fable 5 foi desenvolvido com foco em segurança, permitindo sua aplicação em diversos cenários de uso geral. Detalhes sobre as capacidades e o desenvolvimento estão disponíveis no anúncio oficial.

A atualização também corrigiu um problema no Claude Code que impedia o salvamento e acesso a transcrições de sessões. Essa melhoria visa a robustez da ferramenta para os usuários.
