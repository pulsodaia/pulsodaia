Claude Code ganha mais controle para desenvolvedores.

A Anthropic liberou a versão v2.1.318 do Claude Code. As atualizações focam em registrar interações de "mods", otimizar custos de recursos e clareza sobre credenciais.

A ferramenta agora registra automaticamente respostas quando solicita a ativação de "mods", garantindo histórico. A configuração de `assume_role` no gateway de aplicativos facilita a atribuição de custos por desenvolvedor em projetos grandes.

A opção `effort` no comando `$.model.fork` permite executar tarefas secundárias com esforço reduzido, enquanto usuários do claude.ai veem data de expiração do login.
