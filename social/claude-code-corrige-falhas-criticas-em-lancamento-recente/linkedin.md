Ferramenta de IA para código corrige bugs críticos após lançamento.

A Anthropic lançou uma atualização para o Claude Code, versão v2.1.258, focada em resolver problemas que impactavam a usabilidade. As correções visam restabelecer a estabilidade para usuários de macOS Monterey e solucionar falhas em sessões de trabalho remotas.

Um dos principais pontos abordados foi a regressão que impedia o funcionamento da ferramenta em sistemas macOS 12 (Monterey). Essa falha, introduzida na versão anterior, causava instabilidade para parte dos usuários Apple.

Além disso, foram corrigidas mensagens de erro em sessões remotas e agendadas, que indicavam "mensagens de usuário devem ter conteúdo não vazio". Esse problema interrompia fluxos de trabalho importantes devido a uma reaprovação de permissões não aplicada corretamente.

A estabilidade de ferramentas de desenvolvimento baseadas em IA é fundamental para a produtividade e a confiança no mercado. Correções como essas garantem que desenvolvedores possam contar com a ferramenta sem interrupções.
