IA Generativa agora entende dados textuais sem rótulos prévios.

Pesquisadores desenvolveram a "Zero-Shot Visualization" (ZSV), uma abordagem que permite aos usuários explorar grandes volumes de texto. Em vez de definir eixos de análise com antecedência, os usuários descrevem os conceitos desejados em linguagem natural. Os modelos de linguagem grandes (LLMs) posicionam os documentos em eixos semânticos correspondentes.

Essa flexibilidade abre novas possibilidades para a análise de dados textuais em áreas como monitoramento de notícias e pesquisa acadêmica. A técnica elimina a necessidade de treinamento específico para cada novo tipo de análise, tornando a exploração de corpora mais direta. O trabalho também estabelece um benchmark para comparar diferentes métodos de geração desses eixos conceituais.
