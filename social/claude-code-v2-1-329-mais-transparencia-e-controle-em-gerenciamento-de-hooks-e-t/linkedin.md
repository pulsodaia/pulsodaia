Anthropic atualiza Claude Code com foco em controle e visibilidade para desenvolvedores.

A versão 2.1.329 do Claude Code traz um diálogo de confiança que detalha a declaração de hooks em pastas, aumentando a transparência sobre o que está sendo executado. A atualização também introduz alertas para falhas no carregamento de hooks em ambientes não interativos.

O gerenciamento de tarefas foi aprimorado. O comando `/tasks` agora exibe informações sobre tarefas agendadas, acionamentos programados, objetivos da conversa e forks, permitindo que o usuário pare processos específicos. Servidores recebem uma linha de "Server message" para exibir erros de conexão HTTP remota.

Essas mudanças visam oferecer mais controle e entendimento sobre as funcionalidades e processos automatizados, essenciais para o desenvolvimento seguro e eficiente.
