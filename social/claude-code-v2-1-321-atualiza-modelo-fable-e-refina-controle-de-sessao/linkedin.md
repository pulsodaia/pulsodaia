O Claude Code v2.1.321 chegou com o modelo Fable 5.2 como padrão e novas regras de sessão.

A Anthropic atualizou o Claude Code, introduzindo o modelo Claude Fable 5.2. Ele expande o contexto para 1 milhão de tokens, oferecendo mais espaço para interações complexas com a IA.

A nova versão também refina o controle remoto de sessões. Agora é possível aplicar configurações a todas as sessões através de um arquivo, garantindo consistência. Mudanças no arquivo exigem reinício do comando para serem aplicadas.

Importantes correções de segurança foram implementadas. Vulnerabilidades em requisições OAuth e permissões de execução de comandos foram sanadas, protegendo dados e o sistema.
