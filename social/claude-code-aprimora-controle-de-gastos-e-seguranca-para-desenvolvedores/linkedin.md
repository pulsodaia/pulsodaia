Claude Code agora detalha limites de uso e reforça segurança para desenvolvedores.

A Anthropic lançou atualizações para o Claude Code com foco em transparência e controle. Desenvolvedores que utilizam a ferramenta de assistência à codificação agora recebem avisos mais claros sobre os limites de gastos. Essas notificações incluem o valor exato do limite, o horário de redefinição e a mensagem específica do operador, exigindo que o gateway de acesso esteja na versão mais recente para funcionar.

Além disso, foi implementado um prompt de confiança para diretórios em `claude agents`. Essa medida garante que a ferramenta se comporte de maneira semelhante ao `claude` principal, solicitando confirmação do usuário ao interagir com diretórios considerados não confiáveis, aumentando a proteção.

Correções importantes também foram aplicadas, como a resolução de um erro que substituía tokens de autenticação de longa duração por outros de curta duração, interrompendo sessões "headless". Falhas intermitentes em servidores OAuth no macOS também foram ajustadas.
