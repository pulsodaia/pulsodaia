Atualizações de segurança em Node.js e Python forçam correções urgentes.

Uma falha em chaves privadas de uma autoridade certificadora indiana, a eMudhra, descobertas em 2026, exigiram ações imediatas para proteger comunicações digitais. A vulnerabilidade permitiu a recuperação de chaves privadas de certificados intermediários.

O Node.js respondeu lançando atualizações com novos certificados CA, enquanto a biblioteca `certifi` do Python removeu os certificados raiz comprometidos. Servidores que utilizam o runtime Node.js para verificações de certificado, como os da especificação MCP, são diretamente impactados.

A rápida resposta da comunidade de desenvolvimento foi crucial para mitigar riscos e garantir a integridade dos sistemas.
