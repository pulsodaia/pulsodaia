Claude Opus 5.5 agora processa 1 milhão de tokens de contexto.

A Anthropic atualizou seu modelo Claude Code, introduzindo o Claude Opus 5.5. A principal novidade é a expansão da janela de contexto para 1 milhão de tokens, um salto significativo que permite processar volumes de informação muito maiores.

Essa atualização é crucial para desenvolvedores que lidam com grandes volumes de dados ou precisam de uma compreensão profunda de documentos extensos. A capacidade ampliada abre portas para novas aplicações e análises mais detalhadas.

Além disso, a Anthropic reestruturou a precificação, tornando o uso mais acessível para certas operações. O custo por milhão de tokens para entrada e saída foi ajustado, assim como a precificação para leituras de cache.

A nova versão também traz melhorias na usabilidade da interface e novas variáveis de ambiente para controle de descrições de ferramentas e instruções de servidor.
