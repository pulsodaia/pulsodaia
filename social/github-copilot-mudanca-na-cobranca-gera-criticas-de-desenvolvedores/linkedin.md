GitHub Copilot troca assinatura por cobrança por uso. Desenvolvedores reclamam.

A Microsoft alterou o modelo de precificação do GitHub Copilot. A ferramenta de assistência à codificação agora cobra por tokens consumidos, em vez de uma taxa fixa de assinatura.

Essa mudança pegou muitos desenvolvedores de surpresa. A imprevisibilidade de custos é a principal preocupação, especialmente para aqueles que utilizam a ferramenta intensivamente.

Para o mercado brasileiro, isso significa uma nova variável nos orçamentos de desenvolvimento. A previsibilidade de gastos, antes um ponto forte, agora é questionada.
