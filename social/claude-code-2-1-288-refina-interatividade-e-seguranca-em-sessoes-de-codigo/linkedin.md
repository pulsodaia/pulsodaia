Claude Code 2.1.288 melhora a usabilidade para desenvolvedores.

A Anthropic lançou a atualização 2.1.288 do Claude Code, focando em aprimorar a interação do usuário com o ambiente de codificação. As novidades visam tornar o desenvolvimento assistido por IA mais eficiente e seguro.

Uma das principais adições é a capacidade de recuperar prompts apagados. Ao pressionar a tecla "Para Cima" em um campo de prompt vazio, o usuário restaura o rascunho anterior, incluindo textos e imagens colados. Isso agiliza o processo de experimentação e correção.

Para sessões em nuvem, um comando `gh api` nativo foi integrado, simplificando o uso em ambientes sem a GitHub CLI. Correções no envio de caracteres de controle para o terminal também garantem o processamento correto de nomes de arquivos e erros.

A segurança também foi reforçada com um prompt de reautenticação que aparece caso um servidor MCP solicite escopos OAuth adicionais durante uma chamada de ferramenta.
