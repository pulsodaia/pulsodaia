Claude agora escreve e executa seu próprio código JavaScript.

A Anthropic liberou uma funcionalidade experimental chamada "Code Mode" para seu modelo Claude. Com ela, a IA consegue gerar código JavaScript para interagir com suas ferramentas.

Isso significa que o Claude pode se tornar mais proativo na execução de tarefas, escrevendo a lógica necessária para atingir um objetivo. A gestão dessa funcionalidade pode ser feita pelas organizações.

A atualização também traz melhorias na validação de plugins. O sistema agora garante que apenas ferramentas compatíveis sejam carregadas, evitando conflitos e assegurando a integridade. A validação de tipos em hooks de plugins foi aprimorada, reportando inconsistências como avisos ou falhas.
