Claude Code 2.1.179: fim das conexões intermitentes e melhorias diretas para desenvolvedores.

A Anthropic atualizou o Claude Code, focando em estabilidade e experiência do usuário. A versão 2.1.179 corrige falhas de conexão que interrompiam a geração de respostas e podiam exibir erros brutos.

As melhorias garantem a preservação de respostas parciais, evitando perdas de trabalho. A rolagem do mouse no WSL2 dentro do Windows Terminal e VS Code foi restaurada, um incômodo da versão anterior.

A gestão de permissões em sandboxes também foi otimizada, resolvendo problemas de instabilidade em sessões Linux. A interface de feedback e a tela de boas-vindas também receberam ajustes pontuais.
