Hugging Face quer que a IA use mais a ciência pública.

A plataforma de IA, Hugging Face, lançou o Projeto ProtoStar. O objetivo é preparar e disponibilizar dados de pesquisas científicas financiadas com dinheiro público para o treinamento de modelos de inteligência artificial. Isso visa agilizar descobertas em diversas áreas.

A iniciativa busca criar ferramentas e padrões para tornar a ciência pública "AI-ready". A ideia é remover barreiras e permitir que pesquisadores usem essas informações de forma mais eficaz.

A democratização do acesso a dados científicos de qualidade é fundamental para o avanço da pesquisa. Projetos como este podem ajudar cientistas brasileiros a aplicar modelos de IA em dados de pesquisas financiadas pelo governo.
