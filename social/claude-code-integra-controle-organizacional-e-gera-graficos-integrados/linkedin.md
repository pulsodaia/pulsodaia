Novas camadas de segurança e visualização de dados chegam ao Claude Code.

A Anthropic atualizou o Claude Code para a versão v2.1.330, focando em controle corporativo e geração automática de gráficos. A autenticação agora se alinha às políticas de organizações gerenciadas via Console de Administração Empresarial, exigindo login e aplicando configurações de segurança.

O módulo "easel" introduz a capacidade de gerar gráficos a partir de dados, uma ferramenta útil para desenvolvedores que precisam visualizar informações complexas. Essa funcionalidade está disponível nas versões Pro, Max e Team/Enterprise para macOS e Linux.

Configurações de ambiente permitem maior controle sobre o processo de login e a exibição de links, facilitando a integração em fluxos de trabalho automatizados e a resolução de problemas.
