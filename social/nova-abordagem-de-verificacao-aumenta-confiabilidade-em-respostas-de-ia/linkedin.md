Modelos de IA ainda geram respostas imprecisas. Uma nova pesquisa propõe um método para resolver isso.

A seleção da resposta mais confiável entre as geradas por modelos de linguagem grandes (LLMs) e modelos visuais de linguagem (VLMs) é um desafio constante. Métodos atuais como autoconfiança do modelo ou juízes treinados apresentam limitações, pois uma resposta pode soar convincente, mas conter erros factuais ou lógicos.

Uma nova metodologia publicada no arXiv introduz um sistema de pontuação adaptativo. Ele combina verificações obrigatórias e rigorosas com avaliações mais flexíveis para garantir a precisão.

O framework proposto utiliza um modelo de rascunho para gerar candidatas, um modelo de configuração para ponderar verificações específicas da tarefa e modelos de pontuação para avaliar a conformidade. Essa abordagem visa aumentar a confiabilidade das saídas de IA.
