Claude Code v2.1.301: Novas regras para retentativas e observabilidade.

A atualização v2.1.301 do Claude Code introduz a variável `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`. Essa configuração permite que o modo de retentativa automática encerre requisições que excedem limites de uso com tempos de reset muito longos, otimizando o uso de recursos.

O projeto também oferece agora diretrizes detalhadas para integrar rastreamento com OpenTelemetry através da skill `claude-api`, facilitando a monitoração de desempenho.

Para desenvolvedores, melhorias incluem o comando de movimento `%` no editor Vim para saltar para colchetes correspondentes e um novo campo `rows` no módulo `Input` para entrada de texto em múltiplas linhas no terminal.
