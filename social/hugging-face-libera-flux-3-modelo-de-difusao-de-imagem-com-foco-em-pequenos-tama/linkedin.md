Modelos de IA para gerar imagens pesam menos.

A Hugging Face lançou o FLUX.3 Image, um modelo de difusão otimizado para rodar com menos recursos computacionais.

Isso significa que a criação de imagens complexas por IA se torna mais acessível, mesmo para quem não tem hardware de ponta.

A novidade pode democratizar o acesso a ferramentas criativas no Brasil, onde o acesso a GPUs potentes é um desafio para muitos.
