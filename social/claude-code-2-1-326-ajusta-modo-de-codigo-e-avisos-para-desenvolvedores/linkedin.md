Anthropic ajusta Claude Code para simplificar o fluxo de trabalho de desenvolvedores.

A versão 2.1.326 do Claude Code traz mudanças focadas em usabilidade para quem trabalha com código via IA. A ativação automática do Modo de Código em equipes de agentes já habilitadas é uma das novidades, eliminando etapas manuais.

Outro ponto importante é o aprimoramento dos avisos. Agora, o sistema alerta o usuário sobre configurações incorretas de ferramentas antes mesmo do início da sessão de codificação, prevenindo erros.

Administradores de servidores também recebem informações mais claras sobre possíveis falhas no carregamento de servidores MCP, especialmente quando arquivos de configuração são adicionados durante sessões ativas.
