Claude Code v2.1.319 traz novas regras para modo automático e integração com terminal.

A Anthropic atualizou o Claude Code, focando em maior controle sobre a execução de código e a comunicação com modelos de linguagem. A principal mudança está no modo automático, que agora nega ou questiona diretamente chamadas não verificáveis pelo servidor, eliminando um fallback anterior.

Para empresas que gerenciam essas configurações, é essencial ajustar variáveis de ambiente como `CLAUDE_CODE_AUTO_MODE_SERVER` para manter o comportamento desejado, especialmente em cenários com gateways de LLM.

A atualização também expande o suporte para tarefas de Managed Code Platform (MCP) no terminal. Quando um servidor MCP executa uma ferramenta, o Claude Code a move para o plano de fundo, otimizando o fluxo de trabalho.
