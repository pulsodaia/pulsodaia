Anthropic atualiza Claude Code com foco em segurança e controle de permissões.

A versão v2.1.246 do Claude Code traz uma nova funcionalidade: um alerta de inicialização para regras de permissão do Bash que usam curingas antes do subcomando. O objetivo é impedir correspondências acidentais e aumentar a segurança.

A interface de permissões agora conta com uma aba "Auto mode", permitindo maior granularidade no controle do comportamento do modelo. Desenvolvedores podem visualizar e editar regras do classificador de forma automática.

A atualização também inclui a exibição do tempo de conclusão de cada turno, detalhando o processamento de solicitações, e corrige bugs relacionados ao modo de tela cheia e ao desempenho com linhas de texto muito longas.
