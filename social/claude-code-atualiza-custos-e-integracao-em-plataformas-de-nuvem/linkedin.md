Claude Code ajusta precificação para residência de dados nos EUA.

A Anthropic atualizou o Claude Code para a versão v2.1.239, introduzindo mudanças significativas na estimativa de custos. Para ambientes que exigem residência de dados nos Estados Unidos, há um acréscimo de 1.1x nos custos de inferência, refletindo as particularidades desses cenários.

A experiência inicial para novos usuários em plataformas como Bedrock e Vertex AI foi aprimorada com uma oferta de renderização em tela cheia única. Isso garante que as novas instalações já comecem com uma configuração otimizada.

Para desenvolvedores Python, a migração de projetos da biblioteca `anthropic` 0.x para a 1.x foi facilitada com o novo comando `/claude-api upgrade`. A referência de Python também foi atualizada, com timeouts agora usando `anthropic.Timeout`.
