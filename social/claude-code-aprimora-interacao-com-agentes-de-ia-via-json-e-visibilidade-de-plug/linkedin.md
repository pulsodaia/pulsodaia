Claude Code ganha JSON para listar sessões e visibilidade de plugins.

A versão v2.1.145 do Claude Code introduz o comando `claude agents --json`, permitindo que desenvolvedores integrem agentes de IA em fluxos de trabalho com mais automação. A saída em JSON facilita a gestão de sessões com ferramentas como tmux-resurrect.

As melhorias também incluem a exibição de informações de repositórios e Pull Requests do GitHub diretamente na linha de status do terminal. A contagem de agentes aguardando entrada agora aparece no título da aba, agilizando a identificação de tarefas pendentes.

Esses avanços visam simplificar a adoção e o uso de agentes de IA, especialmente no contexto brasileiro, onde a integração de ferramentas de IA em processos de desenvolvimento é crescente. A visibilidade detalhada das funcionalidades de plugins antes da instalação também contribui para uma decisão de adoção mais informada.
