Claude ganha camadas extras de controle e segurança.

A Anthropic atualizou seu modelo de linguagem Claude, priorizando a proteção de dados do usuário. Novas funcionalidades buscam impedir que informações sensíveis, como o e-mail da conta, sejam compartilhadas sem permissão explícita.

Para desenvolvedores, a versão v2.1.317 do Claude Code introduz avisos sobre conectores não solicitados em tarefas agendadas e exige confirmação antes que ferramentas de web ou shell enviem o e-mail do usuário. Para quem usa o Agent SDK, callbacks de hooks com falha agora bloqueiam a ação principal.

No Claude Desktop, os usuários serão notificados sobre o status do carregamento de configurações remotas e quando o modo automático não encontra resposta para chamadas de subagentes.
