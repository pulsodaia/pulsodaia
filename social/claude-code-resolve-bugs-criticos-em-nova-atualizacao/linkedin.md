Anthropic ajusta Claude Code para desenvolvedores.

A versão v2.1.173 do Claude Code, lançada pela Anthropic, traz correções focadas em usabilidade e confiabilidade. A atualização normaliza nomes de modelos, removendo sufixos redundantes para o Fable 5.

Também foi corrigido um alerta de sistema "sandbox dependencies missing" que aparecia indevidamente no Windows. Essa melhoria visa a clareza da interface e a sensação de estabilidade para quem usa a ferramenta.

As mudanças simplificam a identificação de modelos e eliminam avisos desnecessários, aprimorando a experiência geral do desenvolvedor no ambiente de IA.
