Ferramenta de IA para desenvolvedores sofre travamento crítico em distribuições Linux.

A Anthropic lançou uma atualização para o Claude Code, ferramenta que auxilia no desenvolvimento de software com IA. A versão v2.1.245 corrige um problema que causava falhas na inicialização em sistemas Linux específicos.

A instabilidade afetava distribuições que utilizam a biblioteca glibc na versão 2.44, como Arch Linux, CachyOS e Fedora Rawhide. Esses sistemas, conhecidos por adotarem rapidamente novas versões de componentes, impediam o funcionamento do Claude Code.

A correção visa garantir a estabilidade para desenvolvedores brasileiros que utilizam Linux em seus ambientes de programação e experimentação com IA. A disponibilidade da ferramenta sem falhas é crucial para a produtividade.
