Claude Opus 4.8 agora opera com modo de alto esforço por padrão.

A Anthropic apresentou atualizações significativas para seu modelo de linguagem Claude. A versão Opus 4.8 chega com um modo de alto esforço ativado por padrão, ideal para tarefas que demandam maior capacidade de processamento.

Uma das novidades mais impactantes são os fluxos de trabalho dinâmicos. Essa funcionalidade permite ao Claude orquestrar a colaboração de dezenas ou centenas de agentes em segundo plano. Isso abre portas para a execução de projetos mais complexos e ambiciosos.

O modo rápido para o Opus 4.8 também foi otimizado, oferecendo o dobro da velocidade padrão por um custo apenas 2.5 vezes maior. O "lean system prompt" agora é o padrão, tornando as interações mais diretas, a menos que o modelo precise de contexto adicional.
