Claude Code V2.1.261 atualiza controle de saída e ferramentas para agentes.

A Anthropic liberou a versão v2.1.261 do Claude Code, focada em aprimorar o gerenciamento de saídas de comandos e tarefas de subagentes. A atualização introduz novas configurações para expandir o limite de caracteres exibidos diretamente na interface, facilitando a visualização de processamentos mais extensos sem a necessidade de acessar logs externos imediatamente.

Uma novidade importante é a adição de uma linha "Organization policy" nos comandos `/status` e `claude doctor`. Isso ajuda a diagnosticar falhas no carregamento de políticas de organização, especialmente em cenários com problemas de proxy que afetam a comunicação com endpoints.

A versão também traz o parâmetro `--append-subagent-system-prompt-file`. Ele permite carregar prompts de sistema para subagentes a partir de arquivos, uma solução eficaz para prompts que excedem os limites de caracteres da linha de comando.
