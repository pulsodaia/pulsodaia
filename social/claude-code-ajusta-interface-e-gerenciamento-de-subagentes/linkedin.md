Claude Code ganha controle granular e otimização de fluxos de trabalho.

A Anthropic atualizou o Claude Code para a versão v2.1.296, focando em aprimorar a experiência do usuário no Claude Desktop e o gerenciamento de subagentes. As mudanças introduzem maior controle sobre a execução de fluxos de trabalho.

Uma das novidades é a chave `code` no gateway de aplicativos, espelhando as opções da linha de comando e aplicadas diretamente na aba Código do Claude Desktop. A opção `desktop` ativa o modo gateway específico para o Claude Desktop.

A atualização também traz `autoCompactWindow` para subagentes, permitindo que suas janelas de conversa fechem mais cedo que a principal, otimizando o espaço. Para eficiência de recursos, a variável de ambiente `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` permite que agentes de fluxo rodem em um único modelo.

Por fim, `CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS` ajusta o tempo de espera para novas tentativas em caso de solicitações sobrecarregadas.
