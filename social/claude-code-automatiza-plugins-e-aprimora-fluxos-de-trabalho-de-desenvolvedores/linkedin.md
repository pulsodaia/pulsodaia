Claude Code simplifica a vida do desenvolvedor com novas automações.

A Anthropic liberou a versão v2.1.157 do Claude Code, trazendo melhorias diretas para o fluxo de trabalho de quem desenvolve software. A ferramenta agora automatiza o carregamento de plugins, eliminando a necessidade de um marketplace para ativar funcionalidades customizadas.

Para agilizar a criação de novas extensões, o comando `claude plugin init` gera um esqueleto pronto, facilitando o desenvolvimento. O autocompletar de argumentos para o comando `/plugin` também auxilia na escolha de subcomandos e plugins disponíveis.

A gestão de agentes foi aprimorada com a configuração `agent` respeitada em sessões despachadas, permitindo sobrescrita via linha de comando. O componente `EnterWorktree` agora alterna entre "worktrees" gerenciados pelo Claude durante sessões ativas.
