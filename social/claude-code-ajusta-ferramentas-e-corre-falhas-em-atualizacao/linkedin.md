Anthropic ajusta Claude Code com foco em robustez e eficiência para desenvolvedores.

A atualização v2.1.310 do Claude Code introduz a ferramenta de Monitoramento e aprimora o gerenciamento de plugins em plataformas como Bedrock e Vertex. Estas melhorias visam garantir que o modelo opere de forma mais estável, mesmo com a desativação de telemetria ou tráfego não essencial.

Foram corrigidas falhas que causavam a interrupção de requisições em determinados gateways e servidores, especialmente quando rejeitavam valores beta específicos ou mensagens de sistema. O Claude Code agora emprega uma estratégia de retentativas mais eficaz para contornar esses problemas.

Adicionalmente, a atualização soluciona um bug relacionado à limpeza em segundo plano que deletava arquivos recentes, como imagens coladas, sob configurações específicas de `cleanupPeriodDays`. Também foi abordado um problema de compactação após erros de "Prompt é muito longo", que retinha dados excessivos de conversas extensas.
