Claude Code agora oferece mais controle para desenvolvedores.

A Anthropic atualizou o Claude Code com novas cabeçalhas de requisição para gateways de LLM. Essas adições, como `x-claude-code-request-class` e `x-claude-code-agent-type`, permitem uma comunicação mais detalhada entre sistemas. A ativação dessas funcionalidades é feita através de uma variável de ambiente específica.

A nova versão também melhora a experiência do usuário em cenários complexos. Agora, o sistema notifica claramente quando um servidor de comunicação em múltiplos processos (MCP) se desconecta e falha na reconexão automática, guiando o usuário para a pasta `/mcp`.

Uma funcionalidade de "forkar" sessões remotas foi introduzida, permitindo que processos iniciados via controle remoto rodem em segundo plano, liberando a interface principal do aplicativo.

Correções importantes foram aplicadas, incluindo a análise aprimorada de comandos Bash pelo verificador de permissões, evitando que prompts fossem ignorados.
