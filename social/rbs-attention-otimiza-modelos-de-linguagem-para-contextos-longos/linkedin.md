Modelos de linguagem estão mais lentos com prompts longos. Uma nova técnica muda isso.

A fase de "prefill" em modelos de linguagem de grande porte consome muitos recursos, especialmente com prompts extensos. A auto-atenção densa, usada atualmente, torna o processamento inicial um gargalo.

Pesquisadores propõem o RBS-Attention, uma abordagem que seleciona blocos de atenção de forma esparsa. Isso significa priorizar informações relevantes em vez de processar cada token com a mesma intensidade.

A técnica combate a "mean dilution", onde a relevância de um token útil pode ser mascarada por um conjunto maior de dados menos importantes. O RBS-Attention usa uma "rescue branch" para capturar a máxima relevância em cada bloco.
