Claude Code ganha novas ferramentas para testar e controlar a saída de modelos de linguagem.

A Anthropic atualizou o Claude Code com funcionalidades focadas em desenvolvedores. A versão v2.1.269 introduz um comando para avaliação de plugins, permitindo testes pontuados e reproduzíveis em formatos como JSON e HTML.

Essa adição visa facilitar a verificação da eficácia e do comportamento de plugins integrados a modelos de IA.

Outra novidade é o controle de estilo de saída, útil para gerenciar interações em ambientes sem interface gráfica e adaptar a formatação das respostas.

A atualização também melhora a integração com ferramentas de linha de comando, exibindo diffs de arquivos alterados pelo Bash tool.
