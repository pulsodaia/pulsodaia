Anthropic aprimora Claude Code com foco em estabilidade.

A Anthropic lançou a versão v2.1.226 do Claude Code. A atualização, focada em correções de bugs e melhorias de confiabilidade, visa fortalecer a base técnica de ferramentas de desenvolvimento.
