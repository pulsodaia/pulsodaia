ServiceNow encontra um atalho para treinar IA corporativa.

A empresa detalhou o AutoSynthData, uma ferramenta que gera dados sintéticos para treinar agentes de IA. O objetivo é superar a escassez de dados, um gargalo comum no desenvolvimento de inteligência artificial.

A nova abordagem permite que empresas criem dados de alta qualidade, essenciais para casos de uso específicos, sem depender de coleta manual extensa ou dados reais que podem ser confidenciais.

No Brasil, a adoção de IA cresce, mas a falta de dados adequados ainda freia o avanço. O AutoSynthData pode democratizar o acesso a dados de treinamento, acelerando a implementação em setores como atendimento ao cliente e automação.
