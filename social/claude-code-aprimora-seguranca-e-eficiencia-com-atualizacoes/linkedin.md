Novas atualizações no Claude Code reforçam controle e segmentação de acesso.

A Anthropic liberou a versão v2.1.314 do Claude Code, trazendo um foco renovado em segurança e eficiência para desenvolvedores. A plataforma agora implementa restrições de escrita em diretórios de trabalho específicos, prevenindo acessos não autorizados a arquivos fora do escopo definido.

Para ambientes corporativos, a adição de uma lista opcional de grupos no gateway de aplicações Claude permite direcionar desenvolvedores com base em sua afiliação em um Identity Provider. Essa segmentação garante controle granular sobre o acesso a recursos.

As atualizações também visam otimizar a experiência do usuário, com foco em eficiência. A integração com o Amazon Bedrock foi aprimorada com o parâmetro `guardrail_trace`, que permite o registro de filtros aplicados.
