OpenAI volta a usar dados de usuários para treinar modelos, mesmo com exclusão ativada.

A OpenAI anunciou que expandirá a coleta de dados de sessões do Daybreak Blue para o treinamento de seus modelos a partir de 29 de novembro. A decisão gerou controvérsia por incluir dados de usuários que haviam desativado a opção de treinamento.

Inicialmente, a política permitia o uso desses dados confidenciais de cibersegurança sem um opt-out específico, o que provocou reações negativas. Em resposta, a empresa prometeu criar uma opção de exclusão separada para esses dados.

Essa expansão levanta preocupações sobre privacidade e consentimento, ecoando debates anteriores sobre o uso de pesquisas não publicadas para treinamento sem consentimento explícito. A confiança e a transparência no desenvolvimento de IA estão em jogo.
