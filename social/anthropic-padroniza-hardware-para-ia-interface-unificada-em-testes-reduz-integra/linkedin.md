Anthropic quer simplificar a conexão de IA com o mundo físico.

A empresa lançou o Model Hardware Standard (MHS), uma interface unificada para agentes de IA interagirem com hardware. O objetivo é replicar o sucesso do Model Context Protocol no software, acelerando a integração de sistemas de IA com robótica e instrumentos de laboratório.

Em testes, o MHS reduziu o tempo de integração de semanas para horas. Essa padronização promete agilizar o desenvolvimento e a implantação de sistemas autônomos em setores como indústria e pesquisa.

A iniciativa busca criar uma linguagem comum para o controle de diversos dispositivos físicos, abstraindo as complexidades de cada equipamento.
