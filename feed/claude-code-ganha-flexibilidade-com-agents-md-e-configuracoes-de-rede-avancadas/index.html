LANCAMENTO · CLAUDE CODE · 18 DE SET DE 2026

Claude Code Ganha Flexibilidade com AGENTS.md e Configurações de Rede Avançadas

Atualização da Anthropic foca em otimização de fluxo de trabalho e controle de infraestrutura para desenvolvedores.

Por Pulso da IA · 18 de set de 2026 · 4 min de leitura
Imagem: github.com

A Anthropic liberou a versão v2.1.277 do Claude Code, introduzindo suporte ao arquivo AGENTS.md como alternativa ao CLAUDE.md em projetos sem instruções explícitas. A atualização também aprimora a gestão de rede para gateways de aplicativos Claude.

O que aconteceu

A mais recente atualização do Claude Code, versão v2.1.277, publicada em 18 de setembro de 2026, traz mudanças significativas para desenvolvedores. A principal novidade é a introdução do suporte ao arquivo AGENTS.md. Agora, em projetos que não possuem um arquivo CLAUDE.md, o Claude Code recorrerá ao AGENTS.md para obter instruções. Essa configuração pode ser ajustada na seção "Project instructions" dentro de /config. É importante notar que essa funcionalidade ainda não está disponível nas plataformas Bedrock, Vertex ou Foundry.

Além disso, a atualização implementa a variável de ambiente CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1. Esta configuração é voltada para gateways de aplicativos Claude cuja única saída de dados seja através de um proxy de saída. Com ela ativada, cada requisição de saída enviará o nome do host ao proxy, em vez de tentar resolvê-lo localmente. Outra adição relevante para a infraestrutura de rede é a opção de incluir um mapa headers: nas configurações de upstream dos gateways de aplicativos Claude. Isso permite o envio de cabeçalhos estáticos para proxies executados na frente de provedores de serviço. Por fim, uma pequena, mas útil, melhoria visual foi implementada: uma linha indicará quando uma tarefa em segundo plano está aguardando atualização, especialmente quando um painel como /tasks está aberto. Correções também foram aplicadas a sessões envolvendo claude -p e o Agent SDK. Mais detalhes podem ser encontrados no release oficial no GitHub.

Por que importa

Essas atualizações têm implicações diretas para a forma como desenvolvedores brasileiros interagem com as ferramentas da Anthropic. A flexibilidade introduzida pelo AGENTS.md simplifica a configuração de projetos, especialmente em equipes que podem ter diferentes convenções de documentação ou que buscam uma maneira mais dinâmica de gerenciar as instruções para o Claude. A capacidade de usar um arquivo de agentes alternativo pode agilizar a adoção em diversos cenários de desenvolvimento.

No âmbito da infraestrutura, as melhorias na gestão de rede são cruciais para empresas que operam em ambientes com políticas de segurança de rede rigorosas. A configuração CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1 e a adição de cabeçalhos customizáveis via headers: oferecem um controle mais granular sobre como os aplicativos Claude se comunicam com serviços externos. Isso é particularmente relevante para o mercado brasileiro, onde a conformidade com regulamentações de dados e a otimização de custos de tráfego de rede são prioridades. A capacidade de direcionar requisições de forma mais eficiente para proxies pode resultar em melhor performance e segurança.

O que esperar

Com estas adições, a Anthropic demonstra um compromisso contínuo em refinar a experiência do desenvolvedor, focando em flexibilidade e controle. A introdução do AGENTS.md sugere um futuro onde as interações com modelos de linguagem se tornam ainda mais adaptáveis a fluxos de trabalho específicos de cada projeto ou equipe. É provável que vejamos mais funcionalidades que permitam a personalização das instruções e do comportamento dos agentes de IA.

No lado da infraestrutura, as melhorias na configuração de rede abrem caminho para implementações mais robustas e seguras de aplicativos baseados em Claude em ambientes corporativos. A capacidade de gerenciar proxies de saída e injetar cabeçalhos estáticos pode facilitar a integração com sistemas legados ou com infraestruturas de nuvem que exigem configurações de rede específicas. Para o mercado brasileiro, isso significa que ferramentas de IA se tornam mais acessíveis e adequadas para cenários de produção complexos. Os desenvolvedores podem esperar um controle maior sobre a comunicação de seus aplicativos, otimizando tanto a segurança quanto a eficiência. Para mais detalhes técnicos e futuras atualizações, o repositório oficial no GitHub permanece a fonte primária de informação.
